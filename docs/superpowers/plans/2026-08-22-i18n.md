# BitWatch i18n (6 UN Languages) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a 6-language i18n system (ar/zh/en/fr/es/ru) to BitWatch with a dropdown language switcher on both the unlock and watch pages (placed after the VERSION badge), translate all user-facing strings, rename the in-app title "大饼观察Only" → "BitWatch", support Arabic RTL, and ship as V6.2.

**Architecture:** Flat dictionary i18n — no library, no build step (single-file Vue 3 PWA). A `translations` object keyed by language code; a reactive `currentLang` ref drives a `t(key, ...args)` function exposed to the Vue template. `bw-lang` localStorage persists the choice. RTL toggled via `document.documentElement.dir`.

**Tech Stack:** Vue 3 Composition API (CDN), Tailwind CSS (CDN), vanilla JS. No test framework — manual verification.

**Spec:** `docs/superpowers/specs/2026-08-22-i18n-design.md`

## Global Constraints

- **Single-file app:** all logic + template changes go in `index.html`. No new JS files.
- **No dependencies:** do not add any library. i18n is hand-rolled.
- **App name fixed:** the string "BitWatch" is identical across ALL languages. Only surrounding UI text translates.
- **6 languages only:** `ar` (العربية, RTL), `zh` (简体中文), `en` (English), `fr` (Français), `es` (Español), `ru` (Русский). These are the 6 UN official languages.
- **Fallback chain:** `t(key)` → current lang → `zh` → raw key. Never blank.
- **Version bump:** ship as **V6.2** — bump `VERSION` (index.html) and `CACHE_VERSION` (sw.js) together so the SW update flow delivers it.
- **Push every change** (user preference): commit + `git push origin main` after each task.
- **Commit message trailer:** end every commit message with `Co-Authored-By: Claude <noreply@anthropic.com>`.

## File Structure

All work is in **`index.html`** (single-file app), plus a one-line bump in **`sw.js`**. Conceptually the i18n pieces are:

1. **i18n core** (inside `setup()`): `SUPPORTED_LANGS`, `LANG_STORAGE_KEY`, `translations`, `currentLang`, `langMenuOpen`, `detectLang`, `t`, `setLang`, `langLabel` — and the additions to the `return` block.
2. **Template bindings** (~40 strings): replace hardcoded Chinese with `{{ t('key') }}` / `:placeholder="t('key')"`.
3. **JS message bindings** (~20 strings): replace `showToast`/`alert`/`confirm`/`throw new Error` Chinese args with `t('key', ...args)`.
4. **Switcher UI**: dropdown snippet inserted after both VERSION badges.
5. **RTL + styling**: `dir` toggle on init + `<style>` block for dropdown.
6. **Version ship**: bump `VERSION` + `CACHE_VERSION` → V6.2.

Because this is a single file with no test framework, tasks are ordered so each produces a verifiable state in the running app, and the final task is end-to-end manual testing.

					function detectLang() {
						const saved = localStorage.getItem(LANG_STORAGE_KEY);
						if (saved && SUPPORTED_LANGS.some(l => l.code === saved)) return saved;
						const nav = (navigator.language || 'zh').slice(0, 2).toLowerCase();
						return SUPPORTED_LANGS.some(l => l.code === nav) ? nav : 'zh';
					}

					const currentLang = ref(detectLang());
					const langMenuOpen = ref(false);

					function t(key, ...args) {
						const dict = translations[currentLang.value] || translations.zh;
						let s = dict[key] ?? translations.zh[key] ?? key;
						args.forEach((a, i) => { s = s.replace('{' + i + '}', a); });
						return s;
					}

					function langLabel(code) {
						const found = SUPPORTED_LANGS.find(l => l.code === code);
						return found ? found.label : code;
					}

					function setLang(code) {
						currentLang.value = code;
						localStorage.setItem(LANG_STORAGE_KEY, code);
						langMenuOpen.value = false;
						document.documentElement.dir = (code === 'ar') ? 'rtl' : 'ltr';
					}
